DownUnderCTF 2025

Notes on the Rocky and Skippy reverse engineering challenges.

Rocky Challenge

The Rocky challenge uses AES in CBC mode. The key is derived directly from the input string, while the initialization vector (IV) is the reversed key.

The important observation is that the cryptographic parameters are not hidden behind a complicated transformation. Once the key and IV are identified, the remaining task is to decrypt the provided ciphertext. 

import struct
from Crypto.Cipher import AES

key = b"emergencycall911"
iv = key[::-1]

precomputed_data = bytes([
    0x26, 0x58, 0xC0, 0xFB, 0x83, 0xC3, 0x40, 0x84,
    0xB8, 0x2D, 0xE6, 0x0A, 0x89, 0x39, 0x4B, 0x76,
    0xF4, 0x59, 0xBB, 0x18, 0x8B, 0xBF, 0x8E, 0x41,
    0x8C, 0xF9, 0x5F, 0xF5, 0x99, 0x53, 0x4F, 0x92,
    0x76, 0x91, 0xF0, 0x0D, 0x90, 0x01, 0xC5, 0x2B,
    0x53, 0xE0, 0xCE, 0x62, 0x4E, 0x09, 0x2E, 0x7F,
    0x36, 0x78, 0x6C, 0xC7, 0x64, 0xEF, 0xAD, 0xAF,
    0x7F, 0x01, 0xE4, 0x5E, 0x24, 0xFF, 0xC7, 0x7E,
    0x70, 0x77, 0x66, 0x2E, 0x16, 0x93, 0x06, 0x2C,
    0x70, 0x93, 0xD4, 0x98, 0x05, 0xBF, 0x38, 0x33,
    0x20, 0x2A, 0xFA, 0xB6, 0xF3, 0xEF, 0xF4, 0x84,
    0xE9, 0x6A, 0x41, 0x7F, 0x5B, 0x57, 0xBA, 0xAC,

cipher = AES.new(key, AES.MODE_CBC, iv)
decrypted_data = cipher.decrypt(precomputed_data)

print(decrypted_data.decode("utf-8"))

The recovered flag recorded in my notes is: 

DUCTF{In_the_land_of_cubicles_lined_in_gray_Where_the_clock_ticks_loud_by_the_light_of_day}

Skippy Challenge

Skippy is similar to Rocky, but the key and IV are obfuscated using a bitwise right shift. The values are first packed as little-endian 64-bit integers, then each byte is shifted right by one bit to recover the AES key and IV. 

import struct
from Crypto.Cipher import AES

v6_1 = 0xE8BEF2E0E0D2D6E6
v6_2 = 0xBED0E6EAC4BECAD0

obfuscated_key = (
    struct.pack("<Q", v6_1) +
    struct.pack("<Q", v6_2)
)

key = bytes((i >> 1) & 0xff for i in obfuscated_key)

v4_1 = 0xDEDEE4C2CEDCC2D6
v4_2 = 0xDEDEDEDEDEDEDEDE

obfuscated_iv = (
    struct.pack("<Q", v4_1) +
    struct.pack("<Q", v4_2)
)

iv = bytes((i >> 1) & 0xff for i in obfuscated_iv)

enc_data = bytes([
    0xAE, 0x27, 0x24, 0x1B, 0x7F, 0xFD, 0x2C, 0x8B,
    0x32, 0x65, 0xF2, 0x2A, 0xD1, 0xB0, 0x63, 0xF0,
    0x91, 0x5B, 0x6B, 0x95, 0xDC, 0xC0, 0xEE, 0xC1,
    0x4D, 0xE2, 0xC5, 0x63, 0xF7, 0x71, 0x55, 0x94,
    0x00, 0x7D, 0x2B, 0xC7, 0x5E, 0x5D, 0x61, 0x4E,
    0x5E, 0x51, 0x19, 0x0F, 0x4A, 0xD1, 0xFD, 0x21,
    0xC5, 0xC4, 0xB1, 0xAB, 0x89, 0xA4, 0xA7, 0x25,
    0xC5, 0xB8, 0xED, 0x3C, 0xB3, 0x76, 0x30, 0x72,
    0x7B, 0x2D, 0x2A, 0xB7, 0x22, 0xDC, 0x93, 0x33,
    0x26, 0x47, 0x25, 0xC6, 0xB5, 0xDD, 0xB0, 0x0D,
    0xD3, 0xC3, 0xDA, 0x63, 0x13, 0xF1, 0xE2, 0xF4,
    0xDF, 0x51, 0x80, 0xD5, 0xF3, 0x83, 0x18, 0x43
])

cipher = AES.new(key, AES.MODE_CBC, iv)
flag = cipher.decrypt(enc_data)

print(flag.decode("utf-8"))

The recovered flag recorded in my notes is: 

DUCTF{There_echoes_a_chorus_enending_and_wild_Laughter_and_gossip_unruly_and_piled}

Takeaways

  • Identify how cryptographic parameters are constructed before attempting to decrypt data.
  • Pay attention to integer packing and endianness when reconstructing byte arrays.
  • Simple bitwise transformations can be used to obscure constants in a binary.
